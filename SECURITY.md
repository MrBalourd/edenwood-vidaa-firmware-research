# Security and data handling

This repository is intended to remain private. It contains a sanitized research summary, not source captures or downloaded firmware.

## Do not commit

- API keys, access or refresh tokens, cookies, authorization headers, signed URLs, or credentials.
- TV serial numbers, MAC addresses, account identifiers, local network addresses, or other unique device identifiers.
- Raw HTTP traces, packet captures, HAR exports, browser profiles, or files copied from private devices.
- Firmware, app package binaries, keys, certificates, or files whose redistribution rights are unclear.

Use placeholders such as `<REDACTED>` in notes. Before pushing, inspect the staged file list and scan for credential patterns. A private GitHub repository is still hosted by a third party; keep the committed material limited to the sanitized notes in this repository.
